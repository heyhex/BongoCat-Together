# BongoCat Together 使用说明

当前提供 Windows x64 开发构建。无需注册账号，无需自行部署服务器。
本地桌宠可离线使用；联机目前只支持两人。

## 检查更新

通过托盘或「设置 → 关于」点击「检查更新」。只读取 Together Release，包含预发布版；
发现新版本后打开对应 GitHub Release 页面，由用户下载并安装。
自动检查沿用现有开关与间隔，不查询原版 BongoCat 的更新。
Development 和 Production 都可检查，数据目录仍然隔离，不自动替换安装文件。
已发布的 0.1.0 包尚不包含此功能，请使用 0.1.1 或后续版本、或当前源码。

## 启动与连接

1. 在工作区 PowerShell 设置 MSVC 工具链，然后运行 `just dev`：

   ```powershell
   $env:RUSTUP_TOOLCHAIN='1.97.1-x86_64-pc-windows-msvc'
   just dev
   ```

   已生成的优化开发程序 `target/release/bongocat-app.exe` 可从本工作区直接运行；`target/debug/bongocat-app.exe` 用于调试。
   该 exe 依赖工作区的模型资源，不是可单独复制给好友的便携安装包。
   开发构建使用独立 Development 数据目录，不读写生产版数据。

2. 通过托盘菜单打开设置，进入「好友联机」。填写自己的昵称，点击「创建房间」。
3. 点击「复制邀请码」，将其私下交给好友。好友在同页填写昵称、粘贴邀请码，点击「加入」。
4. 两端确认「已连接」与实际路径。邀请码用于首次加入的期限是 10 分钟；房间结束后失效。
   房间只接受首次成功加入的好友身份；重新启动好友程序后需创建新房间。
5. 任一方点击「断开连接」结束房间；异常断线会尝试重连，重连后所有分享仍关闭，需要重新开启。

普通模式可能使用 n0 的公共发现和中继服务。传输使用加密 QUIC；没有账号服务或应用文字存储服务器。
「仅允许直连」会禁用中继，适合可达的局域网或 UDP 环境；受 NAT、防火墙限制时可能失败。
路径和延迟无法取得时显示「未知」，不会编造数值。不要公开邀请码。

## 选择分享内容

所有分享默认关闭，自己的猫始终按原本设置响应本机输入。

- 「分享抽象键盘动画」只发送是否正在按键，不发送具体键码。
- 「分享具体键位」发送物理按键与释放，可显示 Ctrl+C 等组合；它不等于输入法实际产生的文字。
  精确键序列可能透露输入内容，分享时气泡持续显示指示，并提供「停止」按钮。
- 「仅在指定应用中分享键位」填写 executable basename，例如 `code.exe; notepad.exe`，离开输入框或按 Enter 生效。
  空值代表不限制应用；它不识别应用内的密码框。只对具体键位生效。
- 「分享鼠标动作」发送归一化位置、按键、释放和滚轮方向，不发送屏幕、文件或窗口内容。
  动作效果取决于模型；原预置模型没有滚轮/双击专属动作，滚轮方向会短暂显示在气泡。
- 「分享文字」打开专用多行输入框，只有这里主动输入的文字会发送。可修改、删除，最多 512 个 Unicode scalar。
  气泡 10 秒后消失，文字变化后重新显示；长文字在限定高度内滚动。关闭文字分享立即清空好友内容。

「暂停全部分享」暂时停止并清空远端状态，恢复后需产生新输入；「停止全部分享」关闭所有开关。
分享气泡关闭、创建或更新失败、输入 Reset、队列溢出以及断线均停止分享。
文字和按键不写入日志或历史，不读取其他软件输入，也不会把远端事件注入操作系统。

## 双猫与模型

联机后自己的猫与好友猫有独立状态。按原项目窗口操作拖动猫，联机页可选好友模型、缩放、交换位置、隐藏和恢复布局。
好友模型在后台加载，失败保留当前可用猫，并显示通知和「重试好友模型」按钮；也可选择其他本地模型。断开后移除好友猫，保留自己的正常单机显示。

好友会发送模型标识和缩放提示。可用的内置模型自动匹配，缺失或自定义模型使用内置默认猫；资源不会自动传输。
要显示自定义模型，先用原「模型库」功能合法导入，再在联机页显式选择本地模型。
本地手动模型/缩放选择优先于好友之后的提示。目前好友显示偏好和前台应用名单仅在本次应用进程内保留，重启后恢复默认。
隐藏好友猫时隐藏其气泡，但本机仍在分享时保留本机分享指示。

## 当前验证范围

真实 loopback QUIC、授权拒绝/第三设备、断线重连、事件与撤销 contract 已有自动化覆盖。
Windows 原生 smoke 覆盖双 Live2D 窗口、模型切换、缩放/显隐/交换、远端键盘隔离、Unicode 气泡和退出清理。
这些不能代替不同公网双机、真实中文输入法组合输入、物理键鼠/锁屏/睡眠/UAC、多 DPI/跨屏与 8 小时运行验收。
macOS 联机尚未提供；部分其他语言的新文案暂用英文。气泡样式沿用应用主题，尚无独立样式编辑器。

当前没有通过签名、Cubism 再分发及安装升级卸载门禁的正式安装包。
复现与未完成项见 [阶段记录](bongocat-together-plan.md)。
